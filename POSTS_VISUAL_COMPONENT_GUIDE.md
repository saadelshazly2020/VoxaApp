## ?? Event Flow

### Create Post Event Chain
```
CreatePost component
  ? user types & clicks Post
  ? calls postsService.createPost()
  ? API: POST /api/posts
  ? Backend saves to DB
  ? Backend broadcasts via SignalR
  ? Response: { success, post }
  ? emit('post-created', post)
  ? PostFeed receives event
  ? Prepends post to feed
  ? SignalR: Other users receive 'NewPost'
  ? Other feeds update automatically
```

### Reaction Event Chain
```
PostCard component
  ? user clicks React picker
  ? user selects emoji
  ? calls postsService.reactToPost()
  ? API: POST /api/posts/{id}/react
  ? Backend updates DB
  ? Backend broadcasts via SignalR
  ? Response: { success, reaction }
  ? Updates post.myReaction
  ? Updates reactionCounts
  ? SignalR: Other users see update
```
